# MYM Engineering OAuth Information Site

Public-facing homepage and privacy policy for the Google OAuth integrations used
by personal assistants managed by MYM Laboratory & Medical Supply, Inc.
Engineering. The assistants run on company-controlled, self-hosted
infrastructure for authorized business users.

Published with GitHub Pages.

- Homepage: `https://mymsupply-eng.github.io/mym-oauth-info/`
- Privacy policy: `https://mymsupply-eng.github.io/mym-oauth-info/privacy/`

After publishing from the business GitHub account, enter these URLs in the
applicable Google OAuth consent-screen settings.
