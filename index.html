Taro Personal Assistant

Taro is a private personal assistant operated by its owner on self-hosted infrastructure. It helps the owner manage selected Google Calendar and Gmail workflows through explicit, user-directed requests.

Purpose

Taro connects to the owner’s Google account using OAuth. Access is used only to perform tasks requested by the owner, such as reviewing email, checking schedules, and managing calendar events.

Data principles

  • Private use: Taro is not offered to the public or to other users.
  • User control: Google access can be revoked at any time.
  • No advertising: Google user data is not sold or used for advertising.
  • Local operation: OAuth credentials are stored on the owner’s self-hosted machine.

Google API disclosure

Taro’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
